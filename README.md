# Sustainability Knowledge Check

Independent English-language diagnostic application for sustainability decisions in Airbus Defence and Space contexts.

## Learning design

- 15–20 minute balanced diagnostic.
- 36-question bank; every attempt selects 18 questions.
- Exactly three questions from each of six decision areas.
- Scenario, single-choice, true/false, multiple-selection and sequencing interactions.
- Immediate evidence-based feedback after every response.
- Partial credit for multiple-selection and sequencing questions.
- Overall result, score by area and links to the relevant Sustainable Aviation Foundations modules.
- Downloadable personal learning plan.
- Browser-only progress; no account or data submission.

## Run

Open `index.html` in a modern browser. The application is fully static and does not require a build step or server.
